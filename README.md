# Item Manager

Item Manager is a small local web app for managing an item library with tags, cover images, and a dark themed interface.

## Features

- Local Node.js server
- Browser based item management UI
- JSON backed item and tag storage
- Cover image upload support

## Getting Started

Install dependencies:

```bash
npm install
```

Start the server:

```bash
npm start
```

Then open the local address printed by the server in your browser.
